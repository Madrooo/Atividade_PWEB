# Formulário de Esporte Escolar

Projeto simples em HTML para inscrição de alunos em uma modalidade esportiva escolar. O formulário reúne informações da escola, dados do aluno, turno e modalidade esportiva.

## Como visualizar

Abra o arquivo `nome_do_aluno_esporte.html` em um navegador.

## Estado atual

Este projeto está em desenvolvimento. O formulário é apenas uma estrutura visual em HTML; ainda não há estilos CSS nem processamento ou armazenamento dos dados enviados.
